# Contexta / 译境

译境是一款面向单轮和对话场景的 AI 翻译工具。它关注说话人身份、语气和连续对话里的上下文，让译文更接近真实交流。

## 功能

- 单轮翻译：输入原文、目标语言、说话人身份和语气风格，生成更贴合场景的译文。
- 多轮翻译：为双方创建对话会话，按上下文连续翻译消息，适合模拟聊天、邮件往来和跨语言沟通。
- 翻译回译：使用谷歌翻译 API 对译文进行回译以检查 AI 模型的翻译结果，支持回译为非原文语言。
- 历史记录：保存过往翻译，便于回看和复用。
- 请求日志：记录请求、响应和 cURL 命令，方便排查模型接口问题。
- 模型配置：支持 OpenAI 兼容接口，可管理多个 API / 模型预设。
- 提示词设置：内置单轮翻译和对话翻译的系统提示词模板，可按使用习惯调整。

## 版本同步

手动修改 `package.json` 中的版本号后，运行：

```bash
pnpm sync-version
```

该命令会同步更新 Tauri 配置中的版本号。
